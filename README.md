# 🏥 معمل الأمل الطبي – Medical Lab Website

> موقع تعريفي احترافي لمعمل تحاليل طبية، مبني بـ HTML/CSS/JS مع Tailwind CSS — يدعم اللغة العربية بالكامل (RTL)، ومحسّن لمحركات البحث، ومتجاوب مع جميع الأجهزة.

**🔗 Live Demo:** [medical-lab-nu.vercel.app](https://medical-lab-nu.vercel.app)  
**📦 Repository:** [github.com/MohamedYFadl/medical-lab](https://github.com/MohamedYFadl/medical-lab)

---

## ✨ المميزات | Features

- 🌐 **دعم RTL كامل** — واجهة عربية احترافية من اليمين لليسار
- 📱 **Responsive Design** — متجاوب مع الموبايل، التابلت، والديسكتوب
- ⚡ **أداء عالي** — صفحة واحدة (Single Page) سريعة التحميل
- 🎨 **تصميم عصري** — Glassmorphism، gradients، وanimations سلسة
- 🔍 **SEO Optimized** — Meta tags، Open Graph، وTwitter Cards مضبوطة
- 💬 **تكامل واتساب** — Floating button وروابط مباشرة للحجز عبر WhatsApp
- 📝 **نموذج حجز تفاعلي** — مع validation وتأكيد الإرسال
- 🎯 **Scroll Animations** — Reveal effects عند التمرير

---

## 🗂️ أقسام الموقع | Sections

| القسم | الوصف |
|-------|--------|
| **Hero** | صفحة رئيسية مع إحصائيات وبطاقة تفاعلية |
| **Services** | عرض الخدمات الأربع مع أكثر التحاليل طلبًا |
| **Why Us** | مميزات المعمل مع أرقام وشعارات الجودة |
| **Home Visit** | تفاصيل خدمة سحب العينات من المنزل + خطوات الحجز |
| **Testimonials** | آراء العملاء مع تقييمات موثقة |
| **Contact** | بيانات التواصل + نموذج حجز كامل |
| **Footer** | روابط سريعة وتواصل اجتماعي |

---

## 🛠️ التقنيات المستخدمة | Tech Stack

- **HTML5** — هيكل الصفحة مع دعم Semantic elements
- **CSS3** — Custom properties, animations, glassmorphism
- **Vanilla JavaScript** — نموذج الحجز والقائمة المتحركة
- **Tailwind CSS (CDN)** — Utility-first styling
- **Google Fonts** — خطوط Cairo و Tajawal العربية
- **Vercel** — Deploy ومستضافة مجانًا

## 🚀 كيفية التشغيل | Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/MohamedYFadl/medical-lab.git

# 2. Navigate to the project
cd medical-lab

# 3. Open in browser
open index.html
# أو افتح الملف مباشرة في المتصفح
```

> لا يوجد أي dependencies أو build step — الموقع يعمل مباشرة بفتح `index.html`
